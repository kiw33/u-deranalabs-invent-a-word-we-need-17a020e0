make.fun entry for [Invent a Word We Need](https://make.fun/competitions/u-deranalabs-invent-a-word-we-need-17a020e0) — $5.

## Entry

`main.py` (Python 3.13, harness program/v1) writes one newly coined word
plus its one-line definition to `/output/entry.txt`:

> Ghostpause (n.): the silence after your risky text shows 'typing...' and then... nothing.

(89 characters; gate: 1-140 characters, UTF-8, single line.)

## How it works

No network, no randomness, no input — the program writes a fixed string, so
every run produces byte-identical output. See `BUILD-NOTE.md` for the
verification evidence.
